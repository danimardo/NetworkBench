# Gobernanza técnica

**Estado:** propuesta, 2026-09-21. Constitución de referencia: 0.4.0 no ratificada.

Este directorio complementa `ARCHITECTURE.md` sin sustituir las fuentes de verdad:

- `ASSESSMENT.md`: evaluación, riesgos, adopción y decisiones pospuestas.
- `ADRS.md`: decisiones importantes y difíciles de revertir.
- `CONVENTIONS.md`: uso moderno y coherente del stack previsto.
- `QUALITY.md`: estrategia de pruebas, enforcement, quality gates, CI y DoD.
- `PLAN-CHECK.md`: Architecture Check para todo `plan.md`.
- `CONSTITUTION-PROMPT.md`: texto propuesto para el flujo oficial de constitución.

Estos documentos diseñan infraestructura de gobernanza. No crean aplicación, dependencias,
comandos de producto ni decisiones de ratificación. Las discrepancias con documentos superiores
deben resolverse expresamente antes de implementar la parte afectada.
